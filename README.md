# FLOPBOX — site commercial V2 (GitHub Pages)

Site statique sans backend. Déposer `index.html`, `styles.css`, `script.js` et le dossier `assets/` à la racine du dépôt GitHub Pages.

Les visuels de la box sont des **rendus conceptuels générés**, pas des photos du matériel réel ou des promesses de caractéristiques finales. Vérifier que la conception mécanique et radio est réalisable : antennes Zigbee et Z-Wave dans un coffret, alimentation USB-C, thermique, port Ethernet, radio et conformité.

Le bouton d'inscription utilise encore `mailto:contact@florian-pasquier.fr` (à confirmer), aucune adresse n'est enregistrée par le site. Ajouter une politique de confidentialité et des mentions légales avant lancement public. Pas de paiement.

Fichiers image : `assets/flopbox-boitier-concept.webp`, `assets/flopbox-interieur-concept.webp`, `assets/flopbox-vision-concept.webp`.
