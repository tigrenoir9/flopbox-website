# FLOPBOX — Site vitrine fidèle à la maquette

Déposez `index.html`, `styles.css`, `script.js` et le dossier `assets/` à la racine du dépôt GitHub Pages.

- **Important :** l'adresse e-mail `contact@florian-pasquier.fr` est un exemple à vérifier/remplacer dans `index.html` et `script.js`.
- Le bouton d'inscription prépare actuellement un e-mail via `mailto:` ; il ne constitue pas une liste d'attente automatisée. Il faudra connecter un service de formulaire avec consentement avant de recueillir effectivement des inscriptions.
- Toutes les images du produit proviennent de la maquette fournie et sont **conceptuelles**, pas des photographies d'un produit final fabriqué.
- Le support Z-Wave, la compatibilité Matter et les caractéristiques matérielles doivent être validés avant la vente.
- Pour un domaine personnalisé `flopbox.florian-pasquier.fr`, configurez le domaine dans GitHub Pages puis dans la zone DNS ; ne modifiez pas le CNAME du site personnel.
